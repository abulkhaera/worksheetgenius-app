# WorksheetGenius.id

Aplikasi Generator Lembar Kerja Peserta Didik (LKPD) Kurikulum Merdeka berbasis AI.

## Fitur Utama
- **PAUD/TK**: Mewarnai (Vector Line-Art), Cari Perbedaan (Spot 3D), Pola, Tarik Garis, dan Menghitung.
- **SD / SMP / SMA**: Soal pilihan ganda & uraian Kurikulum Merdeka otomatis.
- **Ekspor A4**: Cetak langsung ke format PDF standar A4.
- **Multi-Engine AI**: Mendukung Google Gemini Nano Banana (`gemini-2.5-flash-image`), Puter.js, dan FLUX AI Engine.
